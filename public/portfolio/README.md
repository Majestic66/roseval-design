# 📸 Images Portfolio - Roseval Design

## 📋 Instructions pour remplacer les images

### 📁 Structure des fichiers
Placez vos images dans ce dossier `public/portfolio/` avec ces noms :

```
public/portfolio/
├── fl-renovation.jpg          # Image pour FL Rénovation
├── dpc-immobilier.jpg         # Image pour DPC Immobilier
├── ap-design.jpg              # Image pour AP Design
├── trading-bot.jpg            # Image pour Trading Bot AI
├── cabinet-dentaire.jpg       # Image pour Cabinet Dentaire Montrabé
└── prixfrance.jpg             # Image pour PrixFrance
```

### 🎨 Spécifications des images
- **Format** : JPG, PNG, ou WebP
- **Taille recommandée** : 800x600px minimum (ratio 4:3)
- **Poids** : Max 500KB par image (optimisé pour le web)
- **Qualité** : Haute résolution pour un rendu professionnel

### 🛠️ Outils recommandés pour optimiser vos images
1. **TinyPNG** (https://tinypng.com/) - Compression sans perte
2. **Squoosh** (https://squoosh.app/) - Outil Google gratuit
3. **Photoshop** - Export Web (qualité 80%, progressif)

### 📤 Comment ajouter vos images
1. **Méthode 1** : Glisser-déposer dans VS Code
   - Ouvrez le dossier `public/portfolio/`
   - Glissez vos images depuis votre ordinateur

2. **Méthode 2** : Copier via l'explorateur
   - Copiez vos images dans `C:\Users\PC\OneDrive\Bureau\Roseval design Site\public\portfolio\`

### ✅ Validation
Après ajout des images :
```bash
npm run build  # Vérifier que tout fonctionne
```

### 🔄 Mise à jour automatique
Une fois les images ajoutées, commitez et poussez :
```bash
git add .
git commit -m "📸 Ajout images portfolio personnalisées"
git push
```

**Vercel redéploiera automatiquement avec vos nouvelles images !** 🚀
